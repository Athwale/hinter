# Hinter

Text processing software with AI integration for text suggestions or synonym advice.    
Uses python imports: htmlmin2, wxpython, beautifulsoup4, requests

### AI tools
ramalama serve --host 127.0.0.1 hf://ggml-org/gemma-3-4b-it-GGUF  
Connect to it in the gui using settings.

#### Assets
Icons used: https://commons.wikimedia.org/wiki/GNOME_Desktop_icons

### Requires for building
sudo dnf install gcc-c++ gtk3-devel python3-devel
